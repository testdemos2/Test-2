# Chris Storm — Director / Filmmaker Website

Static GitHub Pages website. No build step is required.

## Included
- New cinematic director/filmmaker design
- English is the default language
- One-click English / German switch
- Responsive mobile navigation
- Chris Storm Kino film archive
- YouTube film cards + in-page player
- About / profile information from the original website
- Contact + booking links
- Original Chris Storm poster used as the hero/profile artwork

## GitHub Pages
Upload the contents of this folder to the `main` branch of a GitHub repository and enable:

Settings → Pages → Deploy from branch → `main` → `/ (root)`

The site uses the existing Chris Storm poster from the original public repository as a fallback image source. If you keep `chris-storm-poster.png` in the same repository, you can later replace the two raw-image URLs in `style.css` and `index.html` with the local filename.

## Default language
English loads first. Press the `DE` button in the top-right corner to switch to German. Press `EN` to return to English.

## Film data
Film titles, years, YouTube IDs and descriptions were carried over from the existing Chris Storm website repository.
